Campus Complaint Management System

A clearer way to report campus issues.

A Java web application where students can submit campus complaints and track their status, while administrators review and update reports.

View source on GitHub Run the application

About this page

This is a static GitHub Pages showcase. GitHub Pages does not run Java servlets, JSP, Tomcat, or PostgreSQL, so sign-in and complaint submission are not available here. To use the interactive app, deploy it to a Java server such as Apache Tomcat and configure its PostgreSQL database.

What the application does

For students

Submit reports about campus facilities and check the status of your complaints.

For administrators

Review submitted complaints and update their status to Pending, In Progress, or Resolved.

Built for Java web

Uses JSP and Jakarta Servlets, with PostgreSQL-backed account login.

Technology

  • Java 21
  • Jakarta Servlet 6.0
  • JSP
  • Apache Tomcat 10.1
  • PostgreSQL
